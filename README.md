## 📌 Featured Project

### 🔹 Praxis – Multi-Agent Conversational Platform

`FastAPI` · `LangGraph` · `React` · `Qdrant` · `Docker` · `AWS`

A central orchestration platform that routes user intent across **Enterprise RAG** and **Deep Multi-Domain Research** agents.  
**Highlights:**

- 🧠 Multi-agent orchestration with LangGraph (Tavily, ArXiv, PubMed, Wikipedia)
- ⚡ Real-time SSE streaming & JWT authentication
- 🌐 Adaptive web-search gating for cost-efficient retrieval
- ☁️ Deployed on AWS EC2 with containerized services

🔗 **Live Demo:** [praxis-ai-nine.vercel.app](https://praxis-ai-nine.vercel.app)  
📂 **Source:** [github.com/smt2208/praxis](https://github.com/smt2208/praxis) *(if public)*
